# Relatório:
## O sistema desenvolvido demonstra como técnicas de prompt engineering podem ser usadas para transformar dados simulados de uma missão espacial em análises inteligentes. A partir dos dados inseridos pelo usuário, a IA consegue identificar possíveis problemas que a tripulação poderá enfrentar durante a missão, classificar riscos, prever falhas e recomendar ações com base no contexto apresentado. Além disso, o controle dos parâmetros do modelo contribui para tornar as respostas mais seguras, objetivas e adequadas a um cenário técnico.
